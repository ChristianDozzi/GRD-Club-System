 # Website Build Brief

 ## 1. Project Overview

 Create a single-page website based on the approved Figma design.

 ## 2. Design Reference

 Use the designed figma frame as the primary visual reference.

 Inspect the design using the available MCP tools before implmentation

 ## 3. Page Structure

 Identify the sections in the figma design, in order
 
 List each section, document:

 - Purpose
 - Content
 - Layout
 - Typography
 - Colours and background
 - Assets
 - Important spacing and alignment
 - Its relationship to adjacent sections

 ## 4. Design system

 Document the Verified:

 - Color palette
 - Typography
 - Spacing
 - Content widths
 - Grid and alignment
 - buttons and other interface components


 ## 5. Technical Requirements

 Build a complete, single-page website using semantic HTML, CSS,  and Javascript only where needed.

 ## 6. Responsive behaviour

 Adapt the layout for desktop, tablet, and mobile. Preserve content hierarchy and usability

 ## 7. Acceptance Criteria

 The site must:
 
 - include every required design section
 - Use the correct available assets.
 - Match the design's visual hierarchy
 - Work at different viewport widths
 - Have no broken local asset references
 - be reviewed in a browser before completion
