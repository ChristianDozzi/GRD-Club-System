# Graphic Design Club

This is a responsive, dependency-free single-page implementation of the approved
`GD-club` Figma frame.

## Structure

- `index.html` contains the semantic page sections.
- `css/styles.css` contains design tokens, layout, typography, and responsive rules.
- `js/main.js` provides the mobile navigation toggle.
- `assets/images/` contains the locally downloaded Figma SVG assets.

The Figma design contains grey placeholder blocks rather than final photography,
social icons, or project artwork. Those areas remain explicit placeholders until
the final content is supplied.
